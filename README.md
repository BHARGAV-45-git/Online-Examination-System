# Online Examination System

## Project Overview

The Online Examination System is a frontend-based web application developed using HTML, CSS, and JavaScript.

The system allows students to register, log in, attend online examinations, submit answers, and view their results.

It also provides an Admin Module to manage examination questions, create exams, and view student results.

## Technologies Used

- HTML
- CSS
- JavaScript
- Local Storage

## Main Modules

### 1. Admin Module

The Admin Module allows the administrator to:

- Login to the admin panel
- Manage examination questions
- Create and manage exams
- View student results
- Logout from the system

### 2. User / Student Module

The User Module allows students to:

- Sign up for an account
- Login to the system
- Access the student dashboard
- Attend the online examination
- Submit the examination
- View examination results
- View profile information
- Logout from the system

## Key Features
